# Canteen Sales Analysis Project

This is my Python project for the canteen sales analysis. It reads data from a file and calculates the total money made.

## Project Files
* main.py - This contains my python code.
* sales.csv - This has the data for food items like Samosa, Noodles, and Sandwich.

## Requirements
* Python 3 installed on your computer.
* No extra libraries needed.

## How to Run the Project
1. Open your terminal or VS Code terminal.
2. Type this command and press Enter:
   python main.py

## What this project shows:
* Money made by each food item.
* Total revenue of the canteen.
